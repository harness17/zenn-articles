# YouTube のプレイリストを投稿日順で追いたくて Chrome 拡張を作った

YouTube のプレイリストを見ていて、「これ、投稿日が古い順に追えたら楽なのに」と思うことがあります。

シリーズものの動画、配信アーカイブ、学習用の再生リストなどは、プレイリストに追加された順番よりも、動画が公開された順番で見たい場面があります。

ただ、YouTube の標準 UI では、自分が見たい並び順にできない場面があります。長いプレイリストだと、どれが古い動画なのかを目で追うだけでも手間です。

そこで、プレイリストを投稿日順に並び替えて、その順番で次の動画へ移動できる Chrome 拡張を作りました。

## 作ったもの

名前は **YouTube Playlist Date Sorter** です。

YouTube のプレイリストページや、プレイリスト再生中のページで、表示中の動画を投稿日順に並び替えます。

できることはこのあたりです。

- プレイリストを古い順 / 新しい順に並び替える
- 並び替えた順番で「次の動画へ」移動する
- 自動 ON にすると、動画終了後に投稿日順で次の動画へ移動する
- YouTube の通常順に戻す
- 日本語 / English を切り替える
- 右下パネルを最小化する

対象は、次のような URL です。

- `https://www.youtube.com/playlist?list=...`
- `https://www.youtube.com/watch?...&list=...`

## こういうときに使いたい

自分の場合は、配信アーカイブやシリーズものを追うときに欲しくなりました。

たとえば、過去の動画から順番に追いたいシリーズ、配信アーカイブ、学習用の動画リストです。プレイリストは便利ですが、順番が自分の見たい時系列と違うことがあります。

この拡張を使うと、表示中の動画に投稿日順の番号が付きます。古い動画から順番に見たいときや、新しい動画から追いたいときに使えます。

## API キーなしで使えるようにした

YouTube Data API は使っていません。

API キーを作ったり、Google Cloud Console を設定したりしなくても使える形にしたかったからです。

この拡張では、ページ上に表示されているプレイリストの情報と、各動画ページの HTML から投稿日を読み取っています。プレイリストそのものの順序や、YouTube 側のデータは変更しません。

あくまで、ブラウザ上で見えている順番と、次に開く動画を拡張側で制御しています。

## 注意点

YouTube のページ構造に依存しているので、YouTube 側の変更で動かなくなる可能性があります。

また、長いプレイリストを完全に読み込むものではなく、ページ上に読み込まれている動画を対象にします。まずは、自分が普段見る範囲で便利に使えることを優先しました。

Chrome Web Store に公開済みなので、通常の Chrome 拡張として追加できます。
