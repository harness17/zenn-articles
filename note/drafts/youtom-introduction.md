# YouTube の配信予定を見逃しやすいので、Youtom というWindowsアプリを作った

YouTube で複数のチャンネルを追っていると、「今日どの配信があるのか」を確認するだけでも意外と手間がかかります。

登録チャンネル画面を見ても、動画、配信予定、ライブ中の枠が自分の見たい順番で並ぶとは限りません。あとで見ようと思っていた配信も、別の新着動画に埋もれてしまうことがあります。

自分の場合は、配信予定を日付順に見たい、ライブ中のものをすぐ見つけたい、気になった配信をあとで確認できる場所に残したい、という小さな不便が重なっていました。

そこで、YouTube の配信予定やライブ中の動画をまとめて見るための Windows デスクトップアプリを作りました。

## 作ったもの

名前は **Youtom** です。

YouTube のチャンネルを登録して、配信予定、ライブ中の動画、見逃し、アーカイブ、お気に入りをまとめて見るためのアプリです。

できることはこのあたりです。

- 配信予定やライブ中の動画を一覧で見る
- ライブ中の配信を見つけやすくする
- 気になる配信をお気に入りに残す
- よく見るチャンネルをピン留めする
- 見逃した配信やアーカイブを確認する
- ダークモードで使う
- 簡易モードなら Google 連携なしでチャンネルを手動追加する

最初は「配信予定を時刻順に見たい」という自分用の道具でした。そこから、見逃し管理、チャンネルのピン留め、お気に入り、アーカイブ検索、自動アップデートなどを足していきました。

## こういう人向けです

Youtom は、YouTube を見る全員向けというより、複数のチャンネルや配信を継続的に追っている人向けです。

たとえば、こういう使い方を想定しています。

- 今日の配信予定をまとめて見たい
- ライブ中の配信を見逃したくない
- あとで見るつもりの配信を残しておきたい
- よく見るチャンネルを一覧の上に出したい
- YouTube の通常画面だけだと一覧性が足りない

ブラウザの YouTube 画面を置き換えるアプリではありません。YouTube を開く前に、気になる配信やチャンネルの状態を確認するための補助ツールとして作っています。

## 最初からGoogle連携を必須にしない

Youtom には、簡易モードとフルモードがあります。

簡易モードは、Google 連携なしで使えます。チャンネル URL や `@handle` を手動で追加すると、そのチャンネルの新着動画を RSS から取得します。

フルモードは、YouTube Data API を使います。登録チャンネルの同期、配信予定時刻、ライブ状態、見逃し追跡などをより正確に扱えます。

ただし、YouTube Data API を使うには、Google Cloud Console で OAuth クライアントを作り、`credentials.json` をアプリに読み込ませる必要があります。

開発者なら分かる手順でも、「配信予定を見たいだけ」の人にはかなり重いです。そこで、最初は簡易モードで触れるようにして、必要になった人だけフルモードへ進む形にしました。

## 少しだけ技術的な話

簡易モードでは YouTube の RSS を使っています。

RSS だけなら、Google Cloud Console の設定や API キーは不要です。チャンネルごとの新着動画、タイトル、URL、公開時刻を取得できます。

一方で、RSS では配信予定時刻やライブ状態を安定して取れません。なので、簡易モードでは「新着動画」を見る入口として扱い、配信予定やライブ検出の精度が必要な機能はフルモードに分けています。

ここを無理に一つの画面に混ぜると、「時刻が分かる配信予定」と「公開済みの新着動画」が同じ一覧に並んでしまいます。見た目は便利でも、情報の意味がずれてしまうので、モードとタブを分けました。

また、`credentials.json` がない、壊れている、形式が違うといった場合でも、アプリ全体は止めずに簡易モードで起動できるようにしています。認証まわりの失敗で、RSS だけの機能まで使えなくなるのは避けたかったからです。

## 注意点

現時点の Youtom は Windows 向けの個人開発アプリです。

GitHub Releases から配布していますが、未署名アプリなので、Windows の SmartScreen 警告が出る場合があります。これはコード署名証明書がないアプリで出る一般的な警告です。README には回避手順を書いていますが、不安な場合は無理に実行しないでください。

フルモードを使う場合は、ユーザー自身で Google Cloud Console の設定が必要です。開発者向けの手順に近いので、まずは簡易モードで試すほうが始めやすいです。

また、YouTube 側の仕様変更や RSS / API の挙動変更によって、取得できる情報や表示が変わる可能性があります。

## 作ってみて感じたこと

個人開発アプリは、機能を増やすことよりも「最初に何を要求するか」が体験に効くと感じました。

Youtom も、最初から Google 連携を必須にすれば、できることは増えます。でも、その代わりに初回導入がかなり重くなります。

配信予定を追いたいだけの人には、まずチャンネルを手動追加して新着を見るところから始められるほうがよい。もっと正確に使いたい人には、あとからフルモードを案内する。

そういう分け方にしたことで、自分用ツールだったものを、他の人にも試してもらえる形に少し近づけられました。
