# Amazon の欲しいものリストからセール中の商品だけ見たくて Chrome 拡張を作った

Amazon の欲しいものリストに商品を入れていると、「今セールになっているものだけ見たい」と思うことがあります。

ただ、商品が増えてくると、1つずつ開いて値段を確認するのが面倒です。タイムセールや価格下落の表示はありますが、リスト全体からまとめて探すには手間がかかります。

欲しいものリストは「あとで買うかも」を置いておくには便利です。でも、増えすぎると、値下がりしている商品を探すだけで時間がかかります。

そこで、Amazon.co.jp の欲しいものリストから、セール中の商品だけを抽出する Chrome 拡張を作りました。

## 作ったもの

名前は **Amazon Wishlist Sale Picker** です。

Amazon.co.jp の欲しいものリストを開くと、「セールのみ表示」ボタンを追加します。ボタンを押すと、リスト内の商品をスキャンして、セール中の商品だけに絞り込みます。

できることはこのあたりです。

- 欲しいものリストに「セールのみ表示」ボタンを追加する
- セール中の商品だけに絞り込む
- 割引率フィルターで「○% 以上の割引だけ」を表示する
- lazy load のリストを自動スクロールで読み込む
- ブラウザ内で判定する
- 外部サーバーには送信しない

対象は Amazon.co.jp の欲しいものリストです。

- `https://www.amazon.co.jp/hz/wishlist/ls/*`
- `https://www.amazon.co.jp/hz/wishlist/genericItemsPage/*`
- `https://www.amazon.co.jp/gp/registry/wishlist/*`

## 何をセールとして判定しているか

画面上の表示から、セールらしい情報を見ています。

- タイムセールバッジ
- 打ち消し価格
- 価格下落表示
- セール系のキーワード

正式な価格履歴サービスではありません。Amazon の画面上に出ている情報をもとに、「今見に行く価値がありそうな商品」を拾うための拡張です。

## 外部サーバーには送らない

欲しいものリストの内容を外部サーバーに送る設計にはしていません。

セール判定はブラウザ内で行います。保存するのは、割引率フィルターなどの設定です。

買い物リストはかなり個人的な情報なので、ここは最初から外部送信なしにしました。

## こういう人向け

- Amazon の欲しいものリストに商品をたくさん入れている
- セール中の商品だけをまとめて見たい
- 値下がりしているものから優先して買いたい
- リストを1件ずつ確認するのが面倒

自分用に作ったものですが、同じように「欲しいものリストが増えすぎた」という人には合うと思います。

買うものを増やすためというより、すでに入れてあるものの中から、今見る価値がありそうな商品を探しやすくするための拡張です。

## 注意点

現時点では Amazon.co.jp 向けです。海外 Amazon は対象外です。

また、Amazon のページ構造や表示文言に依存しているため、Amazon 側の変更で検出できなくなる可能性があります。

購入前には、必ず商品ページで価格や条件を確認してください。

Chrome Web Store に公開済みなので、通常の Chrome 拡張として追加できます。
