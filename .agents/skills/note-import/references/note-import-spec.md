## インポート後の扱い

- note にインポートされたデータは「記事一覧」にテキスト記事として下書き状態で追加される。
- インポートの成功 / 失敗は、開始後3日以内にメールで連絡される。
- ほかのサイトからデータをエクスポートする方法は、サイトごとに仕様が違うため note 運営のサポート対象外。

## 対応形式

### WXR形式

- WordPress 形式でエクスポートされる XML ファイル。
- RSS に WordPress の要素が足された形式。
- 文字コード: UTF-8
- 1回にインポートできる容量: 20MBまで
- 1回にインポートできる記事数: 1000件
- このスキルでは、Markdown 原稿から最小構成の WXR XML を生成する場合は WXR を優先する。
- 画像なし・iframeなしの note 宣伝記事なら、WXR の `content:encoded` に HTML 本文を入れる形にする。
- 複数記事を作る場合は、1つの WXR XML に複数の `item` を入れて、note へのアップロード単位を1ファイルにまとめる。

### MT形式

- MovableType 系のエクスポートファイル。
- LINE BLOG 等でエクスポートされる形式。
- note では txt ファイルがインポート対象。
- 文字コード: UTF-8
- 1回にインポートできる容量: 20MBまで
- 1回にインポートできる記事数: 1000件

## インポートされる内容

- タイトル
- 本文
- 画像
- 日時

## 変換時の注意

- 本文中に埋め込まれた URL / iframe や一部文字装飾は、文字列としてインポートされる場合がある。必要なら note 上で再設定する。
- 画像は `img` タグの `src` 属性が `http://` または `https://` で始まる画像 URL の場合にインポートされる。
- 対象画像形式は JPEG / PNG / GIF。
- ローカル画像、相対パス、対応外形式は手動再設定前提にする。
- 画像 URL は元サーバーの URL だが、画像自体は note に保存し直される。
- note 上の公開日は基本的にインポートファイル内の日付になる。
- 2014-04-07 12:00 以前の日付は 2014-04-07 12:00 としてインポートされる。
- インポート日より未来の日付は、インポート日時として扱われる。
- 過去日付の記事は、公開しても新規タイムラインに表示されず、クリエイターページでは該当日付に公開されたものとして表示される。
