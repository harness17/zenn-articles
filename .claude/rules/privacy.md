# 守秘義務・避けるべき内容

## 書いてはいけないこと

| カテゴリ | 内容 |
|---------|------|
| 業務固有情報 | 顧客名、案件名（トランスワード／プロアクティブの受託案件） |
| 個人情報 | 同僚・関係者の氏名、社内連絡先 |
| 体調の詳細 | 療養期間中の症状、診断名、治療経過 |
| 他社批判 | 過去の勤務先・同業他社への否定的言及 |
| 未検証の伝聞 | 「〜らしい」「〜と聞いた」レベルの情報 |

## 一般化のしかた

業務経験を書きたいときは抽象化する：

| NG（具体名） | OK（抽象化） |
|------------|-------------|
| 「〇〇旅行社の予約システムで〜」 | 「ある旅行業の予約システムで〜」 |
| 「客先A社の要求が〜」 | 「ある業務システム要件で〜」 |
| 「先輩の田中さんが〜」 | 「チームのレビューで〜」 |

## 障害・体調への触れかた

- 療養期間（2022〜2026年）には事実ベースで触れる程度に留める
- 過度な自己卑下も美化もしない
- 候補E（AI協調開発）を書くときは技術記事として成立させる範囲で。障害者雇用の文脈は控えめに

## 自己PRの抑制

- 経歴自慢・スキル自慢の比率を抑える
- プロフィールは記事末尾の「著者」欄程度にとどめる
- 内容の有用性で勝負する
