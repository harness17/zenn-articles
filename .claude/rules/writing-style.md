# 文体ルール（Zenn技術記事）

技術記事を生成・編集するときは以下に従う。違反語は `/article-review` スキルでも検出される。

## 避ける表現

| 種類 | 例 |
|------|----|
| 過度な強調 | 「素晴らしい」「驚くべき」「画期的な」「魔法のように」 |
| 〜ing連鎖 | 「実装することで〜することで〜することができる」 |
| 曖昧な締め文 | 「いかがでしたでしょうか」「皆さんも試してみてください」 |
| AI的紋切り型 | 「ぜひ参考にしてみてください」「ご参考になれば幸いです」 |
| 曖昧な主語 | 「〜とされている」「〜と言われている」（一次情報なら断言する） |

## 推奨する書き方

- **体験ベース**：「〜らしい」より「〜した結果〜になった」
- **具体的**：「パフォーマンスが上がる」より「クエリ実行時間が 800ms→120ms に短縮」
- **失敗例を含める**：実務で踏んだ落とし穴は記事の固有価値になる
- **コードと文章を交互に**：抽象的説明 → コード → 実行結果 → 解釈

## 文体チェック

- 公開前に `/article-review` を実行する（違反語スキャンと必須要素チェック）
- 保存時に PostToolUse hook が違反語を警告する（articles/*.md のみ）
